# IT资产台账匹配工具

把台账里的某一列（通常是 IP）拿去资产清单里比对，命中后把业务系统名称写回台账。
Windows 桌面程序，带图形界面，也提供命令行模式。

---

## 为什么要写这个

我干企业网络安全监控，日常要跟两份表打交道：一份是资产探测出来的台账，里面是 IP、端口、漏洞；另一份是资产清单，记录每个 IP 属于哪个业务系统、归谁管。

这两份表必须对上。告警来了，你只知道某个 IP 有高危漏洞，但不知道这是谁的系统，工单就派不出去。

最早我用 Excel 手工做：Ctrl+F 搜 IP，找到了复制粘贴过去。两百来行还忍得了。后来台账变成五百行、上千行，资产清单还被拆成了十几个 sheet，每个 sheet 的列顺序都不一样——「IP地址」这一列在有的 sheet 是第 2 列，有的在第 5 列。手工对一天，眼睛先瞎。

真正让 VLOOKUP 彻底失效的是这几件事：

- 一个单元格里塞了五六个 IP，用换行或者顿号隔开，得逐个搜
- 有的单元格直接写 IP 段，比如 `172.16.11.46-48`
- 台账表头上面还压着两行标题说明，表头不在第 1 行
- 同一个 IP 在不同 sheet 里叫法不一样，有的带空格，有的是全角字符

所以先写了个脚本自己用，后来加上界面给同事也能用，就成了这个工具。

## 怎么用

### 界面

窗口分上下两部分：上面三张配置卡，下面是匹配结果的台账表格。

顶部三张卡片，从左到右：

**① 待匹配台账** — 要被回填的那个文件
- 文件：浏览选择，或直接拖路径进去
- 工作表：选哪个 sheet
- 表头行：表头在第几行，默认 1。程序会扫前 12 行找像表头的那一行
- 源列（比对）：台账里拿去比对的那一列，比如「IP地址」

**② 资产清单** — 提供匹配依据的文件
- 查找列（比对）：清单里和源列对应的那一列
- 返回列（取值）：命中之后要取哪一列的值，比如「涉及业务系统/设备」
- 工作表默认「（全部工作表）」，即所有 sheet 都翻一遍

**③ 输出设置**
- 回填到：写回台账的哪一列，下拉最后一项「新建列…」可以在表格末尾加一列
- 匹配模式：见下表
- 未匹配填充：没匹配上时填什么，留空就是不填

填完点 **开始匹配**。下方表格会显示匹配后的台账，绿点表示已匹配，红点表示未匹配，表格可以上下左右滚动。核对没问题后点 **导出最终台账** 另存成一个新文件（不会覆盖原文件）。

### 四种匹配模式

| 模式 | 干什么 | 什么时候用 |
| --- | --- | --- |
| 智能（优先提取IP，无IP则整格） | 格子里有 IP 就按 IP 比对，没有就整格比对 | 不确定数据长什么样，先用这个 |
| 仅提取 IP（一格多IP自动拆分） | 只认 IP，其他内容忽略 | 列里混了主机名、备注、端口 |
| 整格精确匹配 | 两边内容完全一样才算命中 | 比对资产编号、MAC 地址这类不会变形的值 |
| 按分隔符拆分匹配 | 按分隔符切开后逐个比对 | 比对域名列表、端口列表 |

「按分隔符拆分」识别的分隔符：换行、制表符、逗号、分号、顿号、斜杠、竖线、空格，中英文符号都认。

比对前会做全角转半角和去首尾空白，所以 `１０．０．０．１` 和 `10.0.0.1` 能对上。

### 命令行

```bat
IT资产匹配工具.exe --cli 台账.xlsx 资产清单.xlsx 输出.xlsx
```

第三个参数可以省略，默认在台账同目录生成 `台账名_已匹配_时间戳.xlsx`。

有一点要注意：exe 是按无控制台方式打包的，命令行模式下日志不会打印出来（`print` 直接被丢弃），但文件照样会生成。想看匹配过程日志，用源码跑：

```bat
python IT资产匹配工具.py --cli 台账.xlsx 资产清单.xlsx 输出.xlsx
```

## 几个容易踩的点

**一格多 IP 怎么算**：`192.168.5.9、10.0.0.1` 这种会被拆成两个 IP 分别查，命中多个就用顿号拼起来，比如「对外门户网站、OA办公系统」。

**IP 段**：`172.16.11.46-48` 会展开成 46、47、48 三个 IP。也支持 `172.16.11.46-172.16.11.48`，分隔符 `- ~ — 至 到` 都认。CIDR 写法（`10.0.0.0/24`）不支持，它不会做网段包含判断。

**多 sheet 查找**：选「（全部工作表）」时，每个 sheet 各自按表头名定位列，所以列位置不同没关系。但两个 sheet 的表头名得一致，一个叫「IP地址」一个叫「IP」就只会命中其中一个。

**表头识别**：只扫前 12 行。如果表头在更下面，得在界面里手动指定「表头行」。识别不到含「涉及业务系统」的列时，程序默认走新建列，不会把数据误填进别的列。

**导出**：只写回填那一列，其余内容和原格式原样保留。

## 源码运行

环境：Python 3.13，依赖 `openpyxl` 和 `tkinter`（Windows 官方安装包自带）。

```bat
pip install openpyxl
python IT资产匹配工具.py
```

### 打包成 exe

```bat
pip install pyinstaller pillow
pyinstaller --noconfirm --onefile --noconsole --clean ^
  --name ITAssetMatcher ^
  --icon "%CD%\imag\logo.ico" ^
  --add-data "%CD%\imag\logo.ico;imag" ^
  --add-data "%CD%\imag\logo_128.png;imag" ^
  --add-data "%CD%\imag\logo_ui.png;imag" ^
  IT资产匹配工具.py
```

`--add-data` 的路径必须写绝对路径，写相对路径会按 spec 文件所在目录去解析，一换目录就报找不到文件。中文路径下打包建议先 `set PYTHONUTF8=1`。

- 一次只能配一组列映射，想同时比对 IP 和域名得跑两遍
- 界面里没有撤销，导出前建议在表格里核一遍
